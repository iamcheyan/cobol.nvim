*cobol.nvim*

COBOL editing support for Neovim, with fixed-format guides, smart indentation,
navigation, Copybook lookup, completion, PIC size estimates, folding, and
GnuCOBOL diagnostics. A COBOL language server is not required.

The complete Chinese learning guide, including examples and exercises, is in
README.zh-CN.md at the plugin root.

TREE-SITTER STRUCTURAL NAVIGATION                           *cobol-treesitter*

The plugin attempts to compile a missing tree-sitter-cobol parser (cobol.so)
automatically when gcc, clang, or cc is available. Alternatively, run
./scripts/build_parser.sh or set build = "bash scripts/build_parser.sh" in the
plugin-manager spec. AST features require a usable parser on runtimepath.

Structure scope:
  Focuses the innermost paired block at the cursor. The opener and matching
  END-* receive depth-colored background badges with bold white text; ELSE
  and WHEN branches also receive badges by default. A dashed vertical guide
  connects the opener and closer. Unmatched structures have no scope guide.
  Depth colors: blue #2563eb, amber #d97706, crimson #dc2626, emerald
  #16a34a, purple #9333ea, cyan #0891b2. Configure via structure_scope =
  { enable = true, char = "┆", show_branches = true }.
  Supported pairs: IF, EVALUATE, PERFORM, SEARCH, READ, WRITE, REWRITE,
  DELETE, START, STRING, UNSTRING, XML PARSE, JSON PARSE, EXEC SQL,
  CLASS-ID, METHOD-ID, FACTORY, and OBJECT.

AST Breadcrumb:
  Real-time hierarchical chain (Division > Section > Paragraph > IF > EVALUATE
  > WHEN). The bundled grammar keeps statements, headers and END-* tokens as
  flat siblings, so the chain is rebuilt from the paired structure ranges
  rather than tree ancestry: a WHEN clause and its enclosing IF/EVALUATE are
  resolved by range, and a division, section or paragraph contributes only its
  header line. Exposed through:
  - Winbar: Built-in when show_breadcrumbs is enabled. The breadcrumb is
    clipped from the left on narrow windows so the innermost structures stay
    visible.
  - Statusline: require("cobol.ast").statusline(bufnr)
  - Floating Window: require("cobol.ast").show_breadcrumb_float()

Paired-block ending hints (Waiting Closures Stack):
  The winbar's right edge lists the expected END-* keywords for parsed,
  already-paired blocks containing the cursor, innermost first. :CobolStructure
  sends this list in a notification; the separate Lua call
  require("cobol.ast").show_waiting_closures_float() opens a floating list.
  Missing END-* statements cannot be inferred from this list: unmatched
  openers are not included. Use :CobolLint to detect syntax errors.

Matching Jump (%):
  Normal mode % jumps bidirectionally between block starts and corresponding
  END-* statements (IF <-> END-IF, EVALUATE <-> END-EVALUATE, PERFORM <->
  END-PERFORM, SEARCH <-> END-SEARCH, READ <-> END-READ, WRITE <-> END-WRITE).

Text Objects:
  vaf / vif   Select around / inside IF ... END-IF
  vae / vie   Select around / inside EVALUATE ... END-EVALUATE
  vap / vip   Select around / inside PERFORM ... END-PERFORM

Enhanced Folding & Outline:
  Native foldexpr creates folds for Divisions, Sections, Paragraphs, and data
  items. If another fold provider creates a control-block fold, AST-aware
  foldtext can summarize it (e.g. +-- IF STATUS = "A", +-- EVALUATE TXN-TYPE,
  +-- PERFORM UNTIL EOF); this plugin does not create IF folds itself.
  'foldtext' is a window-local option that other plugins also claim, so
  folding.foldtext decides ownership: "auto" (default) defers to nvim-ufo
  when it manages the buffer, "plugin" always installs the COBOL summary,
  and "off" never touches the option.
  Aerial / Syms outline provides a true multi-level parent-child hierarchy
  containing Sections, Paragraphs, IF, EVALUATE, WHEN, PERFORM, READ, WRITE,
  REWRITE, SEARCH, unquoted CALL, and embedded SQL statements (SQL SELECT,
  SQL UPDATE, etc.).

SETUP                                                               *cobol-setup*

Install cobol.nvim with your plugin manager:

    {
      "iamcheyan/cobol.nvim",
      build = "bash scripts/build_parser.sh",  -- optional prebuild
      ft = { "cobol", "cbl", "cob" },
      opts = {},
    }

The plugin attaches to buffers with filetype cobol, cbl, or cob. GnuCOBOL
(cobc) enables compiler checks and builds. blink.cmp enables completion.
Aerial is optional and provides the searchable Outline sidebar. None of
these optional integrations is required for the other core features.

FIXED-FORMAT SOURCE                                           *cobol-fixed-format*

Fixed-format columns:

  1-6    Sequence area
  7      Indicator: blank for source, * for comment, / for page eject,
         - for continuation
  8-11   Area A: divisions, sections, paragraphs, and high-level entries
  12-72  Area B: statements, clauses, and data items
  73-80  Identification area; source beyond column 72 may be ignored

Default visual guides are at columns 7, 8, 12, and 73. Text past column 72 is
highlighted. :CobolGuideToggle detaches/reattaches the visual guide, winbar,
and diagnostics; it does not uninstall existing buffer mappings or folding.

Normal-mode column motions:

  g7      Indicator column
  g8      Area A
  g12     Area B
  g73     Identification area

In fixed-format Insert mode, <Tab> moves through columns 7, 8, and 12 when
the text before the cursor is whitespace. From column 12 onward it inserts
shiftwidth spaces (4 when shiftwidth is unset or zero). <S-Tab> moves back
through those stops without deleting source to the right. With source text
before the cursor, the mappings fall back to normal editor behavior.

The indentexpr understands common blocks (IF, EVALUATE, PERFORM, READ,
SEARCH, WRITE, EXEC), Area A/B, and data levels. Reindent a line with ==, a
file with gg=G, or a selection with =. This is a helpful heuristic, not a
complete COBOL parser; inspect continuation lines and compiler output.

gcc toggles the current line comment. Visual gc toggles selected lines.
<leader>c* and :CobolToggleComment are also available. Fixed format uses *
in column 7; free format uses *>.

NAVIGATION                                                       *cobol-navigation*

gd jumps to a paragraph, section, or data definition in the current source and
recursively referenced Copybooks. Ambiguous definitions are offered in a
selection list. The plugin provides this navigation without a COBOL LSP.

  gf      Open the Copybook on the current COPY statement
  K       Preview a definition or Copybook in a floating window
  <C-o>   Return to the previous jump location
  <C-i>   Move forward through the jump list

Copybook search paths come from .cobol.json or the copybook_paths plugin
option. COPY ... REPLACING is supported for identifying the Copybook name.
The same configured paths are passed to GnuCOBOL as -I include directories.

COMPLETION AND OUTLINE                                         *cobol-completion*

When blink.cmp is available and completion.enable is true, a COBOL source is
registered for filetypes cobol, cbl, and cob. Candidates include keywords,
verbs, clauses, snippets, symbols in the current buffer, and symbols in
referenced Copybooks. No COBOL language server is needed.

Aerial is optional. Its COBOL backend provides outline symbols for divisions,
sections, paragraphs, file descriptions, and level-01 records. Without Aerial,
the rest of cobol.nvim continues to work.

Folding recognizes Division, Section, Paragraph, and data structure ranges.
Use the built-in Neovim keys za, zc, zo, zR, and zM to toggle, close, open,
open all, and close all folds.

PIC AND RECORD LAYOUT                                           *cobol-calculator*

The calculator shows a field-size hint near data definitions and can produce
a field/offset table for a level-01 record:

  <leader>cr
  :CobolCalcRecord

It estimates common DISPLAY, COMP/BINARY, COMP-3/PACKED-DECIMAL, COMP-1,
COMP-2, elementary OCCURS, and REDEFINES layouts. 88-level conditions do not
occupy independent storage. Group-level OCCURS does not multiply child sizes;
a larger REDEFINES overlay does not increase the estimated total.

These are learning and review estimates, not an ABI guarantee. Compiler
version, dialect, target platform, alignment, separate signs, nested groups,
and OCCURS DEPENDING ON can affect actual storage. Verify production record
sizes with the target compiler and platform.

DIAGNOSTICS AND BUILD                                         *cobol-diagnostics*

When diagnostics are enabled, the plugin runs cobc asynchronously after
save, after a debounced edit, and when leaving Insert mode. This does not
block typing. Copybook diagnostics are mapped to the Copybook and, where
possible, annotated at the COPY line in the source program.

  <leader>cl / :CobolLint       Run a syntax check now
  <leader>cq / :CobolQuickfix   Open diagnostic Quickfix entries
  :cnext / :cprev               Move between Quickfix entries
  :CobolDiagnosticsToggle       Enable or disable automatic checks

Single-file projects without a Makefile use the configured cobc executable:

  :CobolTest    Run a syntax-only check
  :CobolBuild   Compile the current source
  :CobolRun     Compile and run the current source

Project commands read files from disk; save the current buffer first. For
multi-source projects, define build/run/test commands or Makefile targets.
If a project has a build rule but no run target, the plugin does not guess
which executable should run.

PROJECT PROFILE                                                   *cobol-projects*

Place .cobol.json at the project root. The plugin searches upward from the
current file for .cobol.json, Makefile, or a Git root. Relative paths resolve
from the detected root. The profile is optional: when .cobol.json is absent,
Neovim defaults are used silently; invalid JSON or profile fields still produce
an error notification and fall back to safe defaults.

    {
      "source_format": "fixed",
      "dialect": "default",
      "compiler": "cobc",
      "copybook_paths": ["copy", "cpy"],
      "warnings": ["all", "no-obsolete"],
      "compiler_args": [],
      "commands": {
        "build": ["make", "build"],
        "run": ["make", "run"],
        "test": ["make", "test"]
      }
    }

source_format accepts fixed, free, or auto. compiler is an executable name
or path. copybook_paths, compiler_args, and warnings are arrays of strings.
Each commands entry is an argument array executed directly, without a shell.
Makefile targets build/all, run, and test/check are detected when commands
are omitted.

COMMANDS AND MAPPINGS                                           *cobol-commands*

Guide and editing:

  :CobolGuideToggle          Toggle guides, winbar, diagnostics attachment
  :CobolGuideEnable          Reattach guides and diagnostics
  :CobolGuideDisable         Detach/clear them (not mappings/folds)
  :CobolToggleComment        Toggle comments; accepts a line range
  :CobolFormatCase           Uppercase reserved words in range; no range = all

Navigation and layout:

  :CobolGotoDef              Jump to a COBOL definition
  :CobolGotoCopybook         Open the Copybook under the cursor
  :CobolPreview              Preview a definition or Copybook
  :CobolCalcRecord           Show a level-01 record layout estimate
  :CobolStructure            Notify paired-block ending hints (needs parser)

Compiler:

  :CobolLint                 Run a syntax check
  :CobolQuickfix             Open COBOL diagnostics
  :CobolDiagnosticsToggle    Toggle automatic compiler diagnostics
  :CobolBuild                Build the source or project
  :CobolRun                  Build and run the source or project
  :CobolTest                 Run project tests or a syntax check

Default buffer-local mappings:

  g7 g8 g12 g73              Jump to fixed-format columns
  gd gf K                    Definition, Copybook, and preview navigation
  gcc / Visual gc            Toggle comments
  <leader>c*                 Toggle comments
  <leader>cr                 Calculate record layout
  <leader>cl / <leader>cq    Lint / open Quickfix
  Insert <Tab> / <S-Tab>     Fixed-format column stops

<leader> is defined by the user's Neovim configuration. These mappings are
buffer-local and can be disabled with keymaps = false.

CONFIGURATION                                               *cobol-configuration*

Common options and defaults:

  columns                  { 7, 8, 12, 73 }
  show_lines               true
  char                     "│"
  show_winbar              true (breadcrumb / paired-block ending hints)
  show_breadcrumbs         true
  show_waiting_closures    true
  structure_scope.enable   true
  structure_scope.char     "┆"
  structure_scope.show_branches true
  show_hierarchy_hint      true
  show_pic_size            true
  highlight_levels         true
  show_colorcolumn         false
  highlight_overflow       true
  disable_indent_guide     true
  smart_tab                true
  keymaps                  true
  source_format            "auto"
  copybook_paths           common project Copybook directories
  cobc_command             "cobc"
  cobc_extra_args          {}
  folding.enable           true
  folding.foldtext         "auto" (auto, plugin, off)
  diagnostics.enable       true
  diagnostics.on_save      true
  diagnostics.on_change    true
  diagnostics.debounce_ms  600
  diagnostics.warnings     { "all", "no-obsolete" }
  completion.enable        true (only active when blink.cmp is installed)

The source still declares enabled, overflow_col, and smart_comments, but
currently does not consult them for the respective behavior. Do not rely on
these as switches.
