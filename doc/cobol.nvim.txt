*cobol.nvim*

COBOL support for Neovim with fixed-format guides, navigation, completion, PIC
size calculation, folding, case formatting, and GnuCOBOL diagnostics. Aerial is an
optional Neovim plugin that provides a searchable code-structure Outline
sidebar; this plugin supplies its COBOL backend.

SETUP                                                               *cobol-setup*

Install iamcheyan/cobol.nvim with your plugin manager and call:

    require("cobol").setup({})

Aerial is optional. Install it when you want a searchable code-structure
Outline sidebar, then add the COBOL backend to Aerial's `backends` filetype
map.

COMPLETION                                                        *cobol-completion*

When blink.cmp is installed, cobol.nvim automatically registers a completion
source for `cobol`, `cbl`, and `cob` buffers. It provides COBOL keywords,
verbs, clauses, snippets, names declared in the current buffer, and symbols
from referenced Copybooks. A COBOL language server is not required.

Completion is optional. The fixed-format guide, navigation, calculator,
folding, formatting, and diagnostics work without blink.cmp.

CONTEXT COMPONENT                                                   *cobol-statusline*

Use `require("cobol.statusline").component()` with lualine or a similar
status component system. `require("cobol.statusline").get()` returns a string
containing the source format, fixed-format area, breadcrumb, current PIC
field, and enclosing record size. It returns an empty string outside COBOL
buffers. The COBOL winbar includes this context automatically.

===============================================================================
COMMANDS                                                            *cobol-commands*

:CobolFormatCase       Uppercase COBOL reserved words in the current line,
                       a Visual range, or the whole file.
:CobolLint              Run GnuCOBOL syntax diagnostics.
:CobolQuickfix          Open COBOL diagnostics in the quickfix list.
:CobolCalcRecord        Show the current 01 record layout.
:CobolGotoDef           Jump to a paragraph or data definition.
:CobolGotoCopybook      Open the Copybook under the cursor.
:CobolPreview           Preview a Copybook or definition.
:CobolDiagnosticsToggle Toggle compiler diagnostics.
:CobolGuideToggle       Toggle the fixed-format guide.
:CobolBuild             Build the current source or project asynchronously.
:CobolRun               Build and run a single source or call the project command.
:CobolTest              Run project tests or a compiler syntax check.

Build output and compiler diagnostics are placed in the quickfix list. Use
:cnext and :cprev to move between reported locations. Project build commands
read saved files; save the current buffer first.

===============================================================================
GNUCOBOL PROJECTS                                                   *cobol-projects*

Create .cobol.json in the project root to share source format, dialect,
compiler, Copybook directories, and extra compiler arguments:

    {
      "source_format": "fixed",
      "dialect": "default",
      "compiler": "cobc",
      "copybook_paths": ["copy", "cpy"],
      "warnings": ["all", "no-obsolete"],
      "compiler_args": ["-Wall"]
    }

Paths are relative to the detected root. The profile is used by both compiler
diagnostics, completion, Copybook lookup, and builds. If a Makefile has build/all, run, or test/check
targets, the matching commands use those targets. The commands object can
override them with argument arrays, for example:

    "commands": {
      "build": ["make", "build"],
      "run": ["make", "run"],
      "test": ["make", "test"]
    }

Single-source projects without a Makefile use cobc to build, run, or check.
For multi-source projects, define Makefile targets or explicit commands so
that linking follows the project build rules.
If the Makefile provides build rules but no run target, add commands.run or a
Makefile run target; the plugin will not guess which executable to launch.

===============================================================================
CONFIGURATION                                                       *cobol-configuration*

project_root             Project root used for Copybook lookup and cobc cwd.
copybook_paths           Relative directories searched for Copybooks.
cobc_command             Compiler command; defaults to "cobc".
cobc_extra_args          Additional compiler arguments.
folding.enable           Enable structural COBOL folding.
diagnostics.enable       Enable asynchronous compiler diagnostics.
diagnostics.debounce_ms  Delay for TextChanged diagnostics.
completion.enable        Enable the optional blink.cmp completion source.

See README.md and docs/TASKS.md for examples, supported limitations, and the
development checklist.
